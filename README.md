# Seeto.SolutionZ / Bloxstrike

> Lightweight, modular utility suite for Bloxstrike with a CS2-inspired interface.

## Loadstring

`lua
loadstring(game:HttpGet(https://raw.githubusercontent.com/euphonee/Bloxstrike/main/init.lua))()
`

## Features

- **Aim**: Angular FOV silent aim, lethal hitbox priority calculation, target lock.
- **Visuals**: 3D skeleton bone ESP, health indicators, view angle vectors, offscreen directional arrows, spectator monitor.
- **Movement**: Native MovementV2 bunny hop, air-acceleration directional auto-strafe.
- **Skins**: Knife model selector (Butterfly, Karambit, M9 Bayonet, etc.) & per-round dynamic skin cycling.
- **Utilities**: Flashbang screen-burn neutralization with subtle translucent overlay.
- **Interface**: High-performance LinoriaLib GUI with CS2 orange theme, live keybind picker, auto-saving config.

## Default Binds

- **Menu**: Insert / Right Shift
- **Kill / Panic**: K
